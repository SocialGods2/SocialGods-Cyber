WHAT THIS VERSION CHANGES

The original project already contains a large 3D globe, investigations, radio/camera tools, technology layers, device utilities and public-data panels.

AEGIS turns those separate features into a recognizable product: one command layer, mission scenarios, a coherent event stream, system health and keyboard navigation. Existing modules remain available underneath.

DESIGN

Dark aerospace/cyber cockpit aesthetic, consistent hierarchy, fewer competing controls and a clear top-level workflow.

DATA MODEL

Live public data is separated conceptually from synthetic demonstration data so the UI can be used as a portfolio/demo project without pretending simulated signals are real.
